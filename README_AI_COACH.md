# AIコーチ 第1・第2段階 導入手順

1. 本番の `config/config.php` をバックアップしてください。配布ZIPには config.php を含めていません。
2. phpMyAdminで `database/migration_005_ai_coach.sql` を1回実行します。
3. 既存フォルダへ上書きアップロードします。
4. ログイン後、「AIコーチ」タブを開きます。

## 実装内容
- 朝のチェックイン：気分、集中時間、今日のタスク最大3件、相談内容
- AIから朝の短いコーチング
- 夜の日誌：完了タスク、できたこと、困りごと、未完理由、自由日記、明日の方針
- AIから夜の具体的フィードバック
- 日誌履歴
- 日誌で完了チェックした既存タスクを自動的に完了へ更新

## 注意
- migrationを実行する前にAIコーチ画面を開くと、テーブル未作成エラーが表示されます。
- OpenAI APIに失敗した場合でも、日誌保存を止めないため定型フィードバックへフォールバックします。
