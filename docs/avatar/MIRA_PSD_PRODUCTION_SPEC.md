# Mira — Live2D用PSD制作仕様 v0.1

用途：ACTION MAP 90 AI Coach。今回は制作仕様のみ。画像生成、PSD編集、モデリング、SDK公開許諾の判断は行わない。

## 0. デザイン固定と未確認事項

正面・腰上・neutral。長めのダークネイビー〜黒紫の髪、ブルー〜バイオレットの瞳、ネイビージャケット、白トップス、シアン／ブルーアクセント、未来的イヤーデバイス、シンプルなペンダント。腕は少し体から離し、髪で目・眉を隠しすぎない。

この作業では色、顔立ち、髪型、衣装、装飾、体型を変更しない。確定原画そのものは今回の依頼に添付されていないため、実際の欠損箇所、解像度、左右非対称、腕・手の見切れ、Belt／Badgeの有無は未確認。原画を受領し、注釈付き不足パーツ表を作ってから描き足す。「必須パーツ名」は存在しないデザインを追加する許可ではない。

## 2. Layer Naming Convention

- L／Rは**Mira本人から見た左右**。正面画像ではMiraのLが閲覧者の右。受け渡し用の左右図を添付する。
- 葉レイヤー名はPSD全体で一意。ASCIIの英数字＋underscore。空白、スラッシュ、同名、copy／final2等を避ける。
- 連番は01から2桁。版番号はファイル名にのみ付け、再インポート時に部品名を変えない。
- 制作元PSDではFace_Base_Line／Fill／Shade等を使ってよい。Import PSDでは部品内だけを統合してFace_Base等へ戻す。異なる可動パーツを統合しない。
- `Mira_Source_v001.psd`（編集元）、`Mira_Import_v001.psd`（Cubism用）、`Mira_Neutral_v001.png`（比較用）を分ける。編集元のReference／Notesはインポート用に残さない。
- 原画に無いもの・完全不可視で不要なものは部品台帳でN/Aとし、理由とモデラー承認を記録する。

## 3. Hidden Area Redraw Checklist

切り抜きではなく、各部品単独で必要な面を完成させる。描き足し量は予定する頭・身体の動きに合わせてモデラーと決める。一律のピクセル数や回転角を保証値にしない。

- [ ] 前髪下の額を肌色・陰影込みで連続させる。
- [ ] 横髪下の頬、左右の顔輪郭外側を埋める。
- [ ] 耳の隠れ部分とイヤーデバイス下の耳を補う。
- [ ] 顎下から首までつなぎ、頭と首の接続に透明な穴を残さない。
- [ ] 後ろ髪の裏・毛束の重なり・肩の背後を補う。
- [ ] 瞼下の白目、虹彩、瞳孔を可動範囲まで描く。
- [ ] 閉眼時の瞼とまつ毛が重なり、肌に穴や白目の残りが出ない。
- [ ] 口内を十分に描き、開口時に歯・舌の切断面が見えない。
- [ ] ジャケット襟下の白トップスを左右・下方向へ補う。
- [ ] 肩・腕の付け根、袖／カフス／手首の接続面を補う。
- [ ] ペンダント下の衣装、チェーンの重なりを補う。
- [ ] 顔を左右に振った時に露出する部分を頭の前後関係込みで確認する。
- [ ] 隠れ面だけを描き足し、原画の可視面に変更がないことを差分で確認する。

検査：上位部品を非表示にして裏側確認 → 各部品を仮移動して接続確認 → 白／黒／市松背景で縁・穴確認 → 全部品を戻して原画比較。仮移動はSourceの複製で行い、Importの基準座標は変更しない。

## 4. Expression Parts Strategy

MVPの5表情は別キャラクター原画を5枚描く方式ではなく、同じ眉・瞼・目・口を変形する方式を優先。左右の目・眉は独立させる。口内・歯・舌は今回音声なしでも将来開口できる素材を用意する。

| Logical expression | 制作・モデリング意図 | 必要部品 |
|---|---|---|
| neutral | 承認済み原画を基準姿勢とする | 目・眉・閉じた口 |
| smile | 穏やかな目元と口角。笑い過ぎない | 瞼・眉・唇 |
| thinking | 軽い眉変化、視線・口の小変化 | 眉・虹彩・瞳孔・唇 |
| empathy | 穏やかな眉と目元。悲しみ・診断を誇張しない | 眉・瞼・唇 |
| encourage | smileと小さな姿勢変化を再利用 | smile部品・上半身 |

この表は表情制作の提案であり、Miraの顔つき変更の承認ではない。表情プレビュー5枚を制作監修者が承認する。追加の閉眼線、頬色、眉差分が必要になった場合だけ別レイヤーとする。顔全体の表情差分切替はMVPでは不要。

Expressionには姿勢・表情の意図を持たせ、将来のまばたき・Lip Sync・音声stateを直接固定しない。強い閉眼等との競合は後続のモデリングで検証する。未完成の表情はneutralへfallbackする。

## 5. MVP必須／後回し

必須：承認済み可視デザインの全パーツ、頭・髪・左右眉目・口の分離、隠れ面の描き足し、身体／腕／衣装の接続、イヤーデバイス・ペンダント、neutralと5表情に必要な素材、RGB 8bitのImport PSD。

条件付き必須：原画に存在するBelt／Logo_Badge／手、閉眼に必要な差分、袖の追加分割。省略時はモデラー承認を必要とする。

後回し：指ごとの可動、衣装交換、髪型交換、複数ポーズ、極端な頭回転、複雑な髪物理、装飾光の多段演出、声に合わせた口形一覧、Realtime Voice連携。後回しは原画から装飾を消すという意味ではない。

## 6. PSD完成条件

SourceとImportを分ける。ImportはPSD／RGB／8bit／sRGBを基準とし、1部品1ラスターレイヤー、部品内の線・塗り・効果・クリッピングを統合し、レイヤーマスクを適用する。Unsupportedなブレンド・塗り設定や不要なパスを残さない。部品間の分離は維持する。

原画の解像度・キャンバス・基準位置を維持する。解像度不足なら着手前に相談し、無断でAI拡大・縮小しない。透明背景、重複名なし、意図しない空レイヤーなし、色変化なし。Neutral合成が承認原画と一致することが最優先。

実際に固定したCubism Editor／model target versionでImportして全レイヤーを確認する。SDKとの互換性をモデラーと決め、Editor最新版の機能を自動採用しない。PSDの完成はLive2D公開許諾の取得とは別である。

## 7. モデラー向けAcceptance Checklist

- [ ] 確定原画と本仕様の版が一致し、画像の権利・利用範囲が確認されている。
- [ ] 顔・衣装・配色・装飾のデザイン変更がない。
- [ ] Source PSD／Import PSD／Neutral PNG／部品台帳／左右図が揃う。
- [ ] 全葉レイヤー名が一意で、各部品は元位置を維持する。
- [ ] 必須部品が揃い、N/Aや追加分割に承認記録がある。
- [ ] 額・頬・耳・首・後ろ髪・襟・腕接続の隠れ面が完成している。
- [ ] 部品を仮移動しても透明穴・接続線・二重輪郭が露出しない。
- [ ] 目の開閉と視線、口の開閉に必要な素材がある。
- [ ] 5表情の意図・強さ・neutral fallback方針が共有されている。
- [ ] Importの色・透明度・描画順が原画と一致する。
- [ ] 合意したEditor／target versionで読み込み成功、欠落・警告がない。
- [ ] 将来の左右回転・呼吸等の可動範囲と、PSD段階では保証しない範囲が明記される。
- [ ] 編集元と成果物の改変権・商用Web利用権・納品形式が合意される。

PSD合格とリグ合格は別。回転端点・メッシュ崩れ・物理・SDK表示・実機性能はモデリング後の検収に含める。

## 8. AI補助で制作する場合

1. 原画を複製して固定し、部品台帳と不足面に注釈を付ける。
2. 使用するAIサービスの画像利用・保存・学習・商用利用条件と原画の権利を確認する。
3. 必要な隠れ面だけを狭いマスクで補助生成する。顔全体・全身の再生成は禁止。
4. 出力を別レイヤーへ置き、元絵との輪郭・色・筆致を人が補正する。
5. 可視面の差分が出たら元絵へ戻し、承認なしに採用しない。
6. 単独部品検査・合成検査・Cubism Import検査を行う。AI出力から自動合格にはしない。
7. 使用ツール・対象部位・採用差分・承認者を制作ログへ残す。

これは将来の制作手順。今回画像生成は実施していない。

## 9. Photoshop／CLIP STUDIOの作業順序

共通：原画バックアップ → Source作成 → 一意名付与 → 後ろ髪・身体・衣装等の裏側から分離／描き足し → 顔 → 眉目 → 口 → 前髪 → 装飾 → 隠れ面検査 → neutral合成比較 → Import複製 → 部品内統合 → export → Cubism読み込み確認。

Photoshop：原画にロックをかけ、部品ごとのフォルダで線／塗り／マスクを保つ。Import複製に対してRGB・8bit・sRGBを確認し、マスクを適用、必要ならスマートオブジェクト／文字／ベクターを部品単位でラスタライズする。キャンバスを部品ごとに切り詰めない。

CLIP STUDIO：編集元を.clipでも保存可能。インポート用の複製で各部品をラスターレイヤーへ統合し、レイヤーを保持したPSDとして書き出す（画像全体を統合しない）。出力PSDを開き直し、色・透過・レイヤー構成を確認してからCubismへ渡す。

両アプリとも、ショートカットやプラグインの有無に依存した工程にしない。Cubism側のImport結果を最終確認とする。

## 10. 外注への渡し方

依頼パッケージ：承認原画の無加工ファイル、本仕様、色・装飾を変更しない指示、左右図、必要な可動範囲、5表情の意図、出力サイズ、部品台帳、N/A一覧、納品命名、権利条件。

最初に原画を見せて不足面／追加分割／解像度を見積もる。顔・髪・衣装など小単位で中間確認し、可視面変更は別承認。Source PSD、Import PSD、合成PNG、部品台帳、制作ログを納品条件とする。PSD制作費とモデリング費、修正回数、追加部品費、納期、二次利用・実績掲載・AI利用可否を分けて合意する。

契約では独自キャラクターの権利、素材の改変・Web配信・将来音声連携への利用範囲を確認する。Live2D SDK出版許諾は素材制作者への発注契約で代替されない。
