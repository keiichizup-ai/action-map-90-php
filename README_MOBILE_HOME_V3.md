# スマホAIコーチ ホーム画面版

## 画面構成
- ホーム
- チェックイン
- 振り返り
- 日記・履歴

スマホ版では毎日の操作だけを表示し、マンダラ、ロードマップ、
タスク編集、参考動画・書籍、ビジョン画像は「PC版を開く」から移動します。

## ホームのAIコーチカード
優先順位は次の通りです。

1. 夜の振り返り後：AIの振り返りコメント
2. 朝のチェックイン後：AIの朝コメント
3. チェックイン前：今日の最初の未完了タスクを提案
4. 今日のタスクがない：PC版で日付調整を案内

## DB/API
DB変更およびAPI変更はありません。
